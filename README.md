# 楽しい冒険を始まる — ブラウザ版

マクダレン制作のRPGツクールVX Ace作品を、GitHub Pagesでプレイできます。

**[ゲームを開く](https://anonymous51398747310968.github.io/tanoshi-boken-browser/)**

PCの最新版Chrome / Edgeを推奨。方向キーで移動、Z / Enterで決定、X / Escでメニュー・戻る、Shiftでダッシュ。

## 公開用の処理

- 未使用BGM・重複音源・標準素材を整理。全マップとデータベース、スクリプトの文字列参照を確認。動的に参照するカスタム画像・戦闘アニメーション・SEは保守的に保持。
- ゲームパッケージを265.4MiBから100.2MiBに削減。配信用gzipとランタイム圧縮を合わせ、初回転送量は約112MiB（従来の約306MiBから約63%削減）。画像・音声の品質は変更なし。
- パッケージ内部は無圧縮ZIPを維持し、実行時のランダムアクセス性能を確保。gzipは転送時だけ使用。
- Service WorkerでCOOP/COEPと圧縮展開を処理。サーバー独自のHTTPヘッダー設定は不要。
- 初回取得後はOPFS / IndexedDBを利用。パッケージURLは固定して更新時のセーブ識別子を維持し、内容ハッシュでアセットキャッシュを更新。
- Windows実行ファイル・ネイティブDLL・開発ログ・既存セーブ・個人設定は公開物に含めない。
- 元の宿屋ME参照 `Audio/ME/inn` に、元データの `Audio/BGS/inn.ogg` を収録して互換性を補完。

## 保存と制約

ゲーム内の「セーブ」でブラウザ内に保存されます。同じブラウザ・同じ公開URLで続行してください。サイトデータの削除でセーブも消えます。ローカル版や別端末からの自動移行・クラウド同期はありません。

原作にあるスクリプトや全イベントの完全互換を保証するものではありません。動作検証の範囲は `VALIDATION.md` に記録します。

## 配信・再ビルド

GitHub Pagesの配信元は `main` ブランチの `/docs`。`.nojekyll` を含む静的サイトです。ローカル検証はリポジトリ直下で `python -m http.server 8766 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8766/docs/` を開きます。`file://` からは動作しません。

`tools/prepare_pages.py --browser-build <動作確認済みブラウザ版フォルダ> --archive <原作Game.rgss3a>` で公開データを生成します。入力フォルダは元の `web/` 配下のHTML・player.js・ランタイム・完全版mkxpzを含む構成です。原作の配布用フォルダ・編集プロジェクトはこのリポジトリに含めません。データの更新後は `python tools/verify_release.py` と実ブラウザでの確認を実施してください。`build/` は公開・Git管理の対象外です。

WebAssemblyとJSエンジンは未改変の上流配布物です。対応ソース・ビルド手順・サブモジュールの固定コミットは [クレジット](docs/credits.html) を参照してください。プレイヤーへの変更はゲームURL・サイズ・ハッシュ・タイトル・起動通知です。
