クラウドPCでの起動方法

GPUを利用できないLinuxの仮想PCでは、ChromiumのCPU描画（SwiftShader）を指定して起動できます。通常起動でWebGLを作れない場合に試す方法です。ゲームのWebページからブラウザの起動設定を変更することはできません。

Debian・Chromium・X11

クラウドPCのデスクトップでターミナルを開き、一般ユーザーで次を実行してください。CPU描画用の専用ウィンドウが開きます。普段のブラウザは終了する必要がありません。

chromium --user-data-dir="$HOME/.local/share/tanoshi-boken/chromium-cpu" \
  --ozone-platform=x11 --use-gl=angle --use-angle=swiftshader \
  --new-window 'https://anonymous51398747310968.github.io/tanoshi-boken-browser/'

同じ起動設定のシェルスクリプトをダウンロードし、sh play-cloud-linux.sh で起動することもできます。

今後も同じ方法で起動するとセーブを引き継ぎます。普段のブラウザのセーブは専用プロファイルには自動移行されません。CPU描画はGPU描画より遅くなることがあります。ゲーム用のウィンドウとして使用してください。

まだ起動できない場合

新しいウィンドウで 描画診断 を開き、結果と chrome://gpu の「Graphics Feature Status」「Problems Detected」を確認してください。組織のポリシーでWebGLが無効になっている場合や、SwiftShaderライブラリがない場合は、この起動指定だけでは解決しません。

現行のDebian 13の chromium-common はSwiftShaderを含みます。ファイルが不足している場合は、管理者にChromium本体と同じ版の chromium-common の導入を依頼してください。診断結果は外部に自動送信されません。

このランチャーはブラウザのサンドボックスを有効のまま使用します。--no-sandbox や --disable-web-security は不要です。

参考：Chromium公式のSwiftShader起動方法、Debianの同梱ファイル一覧。
